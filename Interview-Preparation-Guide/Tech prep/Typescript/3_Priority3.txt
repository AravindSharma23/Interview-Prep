🔥 Priority 3 — Union & Intersection Types
24. What is a union type?

A union allows a value to have one of several types.

let id: string | number;

id = 10;
id = "abc";

🧠 Easy Memory:

| means OR.

25. How do you narrow a union type?

Use type guards.

function printId(id: string | number) {
  if (typeof id === "string") {
    console.log(id.toUpperCase());
  } else {
    console.log(id.toFixed());
  }
}

🧠 Easy Memory:

Narrowing = use a check to discover the exact type.

26. Difference between string | number and string & number?
string | number

means string OR number.

string & number

means the value would have to satisfy both types. For primitive string and number, there is no useful value satisfying both.

🧠 Easy Memory:

| = OR, & = AND.

27. What is an intersection type?

It combines multiple types.

type Person = {
  name: string;
};

type Developer = {
  language: string;
};

type Employee = Person & Developer;

🧠 Easy Memory:

Intersection = combine multiple requirements.

28. When should you use union vs intersection?

Use a union when a value can be one of several alternatives.

type Status = "success" | "error";

Use an intersection when an object must satisfy multiple types.

type Employee = Person & Developer;

🧠 Easy Memory:

Union chooses; intersection combines.

29. What is a discriminated union?

A discriminated union uses a common property to identify which member of a union you're dealing with.

type Success = {
  status: "success";
  data: string;
};

type ErrorResponse = {
  status: "error";
  message: string;
};

type Response = Success | ErrorResponse;
function handle(response: Response) {
  if (response.status === "success") {
    console.log(response.data);
  } else {
    console.log(response.message);
  }
}

🧠 Easy Memory:

Discriminated union = union + identifying property.

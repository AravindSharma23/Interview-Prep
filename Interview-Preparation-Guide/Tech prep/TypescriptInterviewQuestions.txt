If your goal is **top product-based companies** and you're preparing for **React/Next.js + TypeScript roles**, don't study TypeScript as just syntax. Interviewers usually test whether you understand **type-system behavior, generics, narrowing, utility types, and how TypeScript works with real React code**.


# 🔥 Priority 8 — `keyof`, `typeof`, `typeof` vs `type`

Very important for advanced TypeScript.

### 8. Type Operators

73. What is `keyof`?

```ts
type User = {
    id: number;
    name: string;
};

type UserKeys = keyof User;
```

Result:

```ts
"id" | "name"
```

74. What is `typeof` in TypeScript?
75. Difference between JavaScript `typeof` and TypeScript `typeof`?
76. What is indexed access type?

```ts
type UserName = User["name"];
```

77. What is `keyof typeof`?

Example:

```ts
const roles = {
    admin: "ADMIN",
    user: "USER"
};

type Role = keyof typeof roles;
```

This pattern is **very common in real-world TypeScript**.

### ⭐ Coding Question 8 — Type-safe `get`

Given:

```ts
const user = {
    id: 1,
    name: "Aravind",
    age: 25
};
```

Create:

```ts
get(user, "name")
```

but prevent:

```ts
get(user, "xyz")
```

Expected concept:

```ts
function get<T, K extends keyof T>(obj: T, key: K): T[K] {
    return obj[key];
}
```

**This is an excellent interview problem.**
